OFFLINE DAOC 0.3 - SERVER COMMAND REFERENCE

285 command registrations read from the shipped server assemblies.
Normal commands can still have level, realm, cooldown or state requirements.
GM/admin commands can change or delete game data. Back up before using them.
Descriptions containing a localization key have no matching shipped English text.

COMMON COMPANION COMMANDS
/spawn opens the companion class picker; /spawn <class> creates that class.
/raid 40 or /raid 80 enables a level-50 companion raid (total includes you).
There is no /spawn 40 or /spawn 80 raid-size command.
/aggressive and /defensive control companion engagement.
/grind, /tc and /disband are documented in their registrations below.
Fresh accounts are normal players; the launcher GM option is OFF by default.

  ---------------------------------
  [color] : one number to select the same color for all the item's parts (if empty : colors random for each item's parts)

  or : '/ngg plate' all the armor is in plate and each part take a random color
  ---------------------------------
  [slotNumber] :
  - for weapons : 10 = 'right hand', 11 = 'left hand', 12 = 'two handed', 13 = 'distance'
  - for armors : 21 = 'head', 22 = 'hands', 23 = 'boots', 25 = 'torso', 26 = 'cloak', 27 = 'legs', 28 = 'arms'
  exemple : '/ngg equip 12 ' Add a two handed weapon to the NPC with a random color.

ADMIN ONLY COMMANDS

/account
  Creates new, manages existing, and controls character assignment for accounts.
  /account accountname <characterName>
  Identifies the account associated with the character. This may be used on offline characters.
  /account changepassword <accountName> <newPassword>
  Changes the password associated with an existing account. If a player requests a password reset, verify ownership of the account.
  /account create <accountName> <password>
  Creates a new account with the specified login credentials.
  /account delete <accountName>
  Deletes the specified account, along with any associated characters.
  /account deletecharacter <characterName>
  Deletes the matching character from its associated account.
  /account movecharacter <characterName> <destAccount>
  Moves the specified character to the first available slot of the same realm on the destination account.
  /account status <accountName> <status>
  Sets an account's status (between '0' and '255'), which is used to define custom behaviors.
  /account unban <accountName>
  Removes an account's ban state, if one is active. This command cannot remove IP-only bans ('/ban ip'), but will remove '/ban both' and '/ban account' records.
  Handler: DOL.GS.Commands.AccountCommand

/plvl
  Alters an account's privilege level (plvl) and grants/revokes access to command types depending on the user's plvl. With these commands, accounts may be granted Admin, GM, and Player command access from in-game.
  /plvl command
  Provides additional information regarding the '/plvl' command type.
  /plvl <newPlvl> <playerName>
  Sets the privilege level for a targeted player's account. They will then have access to all commands associated with that role. Use '/plvl single' or '/plvl singleaccount' to retain access to specific command types as a Player.
  /plvl remove <commandType> <playerName>
  Removes a specific command type previously granted to a player using '/plvl single'.
  /plvl removeaccount <commandType> <playerName>
  Removes a specific command type previously granted to a player's account using '/plvl singleaccount'.
  /plvl single <commandType> <playerName>
  Grants a character the ability to perform a specific command type regardless of their current privilege level. For '<commandType>', enter only the command identifier (e.g., 'player' for '/player' commands, 'plvl' for '/plvl' commands, etc.).
  /plvl singleaccount <commandType> <playerName>
  Grants all characters on a player's account the ability to perform a specific command type regardless of their current privilege level. For '<commandType>', enter only the command identifier (e.g., 'player' for '/player' commands, 'plvl' for '/plvl' commands, etc.).
